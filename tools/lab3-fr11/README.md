# Стенд FR-11

Два незалежні тестові чипи задають GPIO та регістри I²C на спільній позначці 5 с. Це контрольовані електричний і реєстровий стимули; вони не моделюють фізичні датчики. У `workspace` — фактична схема і перевірені ELF/HEX. Про результати та межі див. `../../docs/metrics/lab3-fr11-20261101/README.md`.

При відтворенні запишіть UART, створіть новий каталог `workspace/docs/captures`, збережіть окремий VCD і перевірте ELF SHA256. Команда перевірки VCD описана в документі результату. Наявні докази не перезаписувати.
