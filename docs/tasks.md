# Задачі KioskGuard, ЛР3

Стан вимірювань на 01.11.2026: окремий кандидат SysTick/busy-poll має 45 підтверджених синтетичних GPIO-подій у S3, але не експортує CPU/WCET та runtime-піки пам'яті; значення невідомі. Помилка Flash і неперевірені вимоги збережені в [реєстрі результатів](metrics/lab3-observed-20261101/README.md).

Порядок у super loop фіксований. Усі виклики працюють на одному стеку, RTOS немає.

| Задача | Період / подія | Внутрішній дедлайн | FR та вихід |
|---|---|---|---|
| command | 1 мс, до 32 байтів RX | 1 мс для виклику; повний ACK ≤200 мс | FR-08, обмежений бюджет |
| pir | 20 мс | 20 мс | FR-04, OUT, без трактування сеансу |
| adc | 50 мс | 50 мс | FR-07, raw ADC |
| imu | 20 мс; діагностично 10/5 мс | поточний період | FR-05/06, вектор у mg |
| imu retry | 1000 мс за відмови | 1000 мс | FR-12, помилка і відновлення |
| policy | 5 мс | 5 мс | FR-04..13, baseline, механіка, світло, B1 |
| audit | перевірка кожну 1 мс, запис за dirty | 1 мс; erase може перевищити | FR-14, один doubleword або одна erase |
| heartbeat | 1000 мс | 1000 мс | FR-03, LD4 та tick |
| output | перевірка кожну 1 мс, готовність TX | 1 мс, без очікування UART | FR-10/15, EVENT/STAT/EXPORT |

Ці внутрішні дедлайни є цілями планування, а не доведеними максимумами. `late` рахує release lateness + execution > deadline. `skipped` рахує кожен пропущений слот. Повторних викликів для наздоганяння немає. Зміна періоду або перехід IMU у retry починає нову фазу. Перехід між двома різними періодами не додає штучний джиттер.

Числові вимоги продукту: FR-05 ≤200 мс, FR-06 ≤1200 мс зі стійким нахилом, FR-07 ≤500 мс, FR-08 ≤200 мс, FR-11 ≤200 мс. Їх треба звірити з максимумом S3, а не з середнім часом задачі.

ISR USART2 публікує байт і грубу мітку SysTick у SPSC RX. Передача працює через TX IRQ; SysTick підтримує HAL. ISR не виконує flash, форматування або бізнес-правила. У цій збірці `stats` не повертає вимірів CPU/WCET.

PA4 охоплює ADC Start/Poll/Get/Stop; PA6 охоплює транзакцію IMU; PA8 піднятий лише під час справжнього кроку audit. PA7 дає короткий імпульс після реакції на новий PIR HIGH у policy.
