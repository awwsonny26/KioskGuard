# Що залишилося до здачі ЛР1

Власниця: Новаківська Софія Василівна, група ІО-35.

Вимоги: `Materials/SP/LR1.pdf`, с. 6..9; обсяг сенсорів уточнений повідомленням викладача 23.09.2026 у TOPICS.

1. Запустити Ubuntu VM і виконати перевірки з `vm-transfer.md`. Зафіксувати реальну ОС, платформу, команду, дату та результат.
2. Завершити демонстрацію UART/LED саме KioskGuard у Wokwi. Потрібен старт, послідовні tick та блимання PA5, а не лише факт успішної компіляції.
3. Зібрати реальні скриншоти CubeMX Pinout та Clock Configuration, Wokwi UART і плати; осцилограму, якщо її використовували для діагностики. Не підставляти зображення іншого студента.
4. Завершити дослідження компонентів. Для фізичних PIR/LDR обрати точні моделі та отримати офіційні datasheet зі сторінками VCC, струму й сигналів. Повні PDF TDK зараз не завантажено; доступ до індексованих витягів описаний у `hardware-components.md`.
5. Створити редагований звіт і фінальний PDF у сусідній `Lab01/Reports`. PDF за методичкою має також бути в Git-репозиторії для здачі, наприклад `docs/report.pdf`, після порівняння з Reports. Готового звіту зараз немає.
6. PDF повинен мати титульний аркуш, мету своїми словами, процес із реальними скриншотами, точні посилання на коміти, щонайменше п'ять фактичних складнощів із симптомом, причиною, рішенням та комітом, висновки й усі джерела. Таблиця розподілу обов'язків для однієї людини не потрібна. Не вигадувати проблеми для кількості.

8. Користувач має створити приватний віддалений репозиторій, надати викладачу доступ/reviewer, завантажити підготовлену гілку після готовності матеріалів і сам створити PR у main. Тут GitHub-репозиторій не створено, push і PR не виконувались.
