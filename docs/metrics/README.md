# Результати ЛР3

[Дані S1/S2/S3, точний ELF і негативний результат Flash](lab3-observed-20261101/README.md). [Окремий дослід FR-11](lab3-fr11-20261101/README.md). Сирий UART та захвати VCD є у відповідних папках; host-тести й фізичні випробування не підміняють одне одного.

[Додатковий кандидат з вимірюваннями TIM3 та новими S1/S3](lab3-spans-20261101/README.md) має інший ELF; старі та нові заміри не слід змішувати в одному порівнянні сценаріїв.

Попередні TIM3-пілоти збережені як окремі захвати у `../captures/`. Числа інших версій не приписуються поточному кандидатові. CPU/WCET і runtime stack/heap поточною прошивкою не виміряні.
