# UART KioskGuard

USART2 115200 8N1. Команди ASCII завершуються CR або LF; CRLF є одним рядком.

| Команда | Дія |
|---|---|
| service on | Сервіс, механічні/світлові події INFO |
| service off | Контроль, механічні/світлові події WARN |
| baseline | Припиняє попередження до нових 2 с стабільності |
| probe | Реальне читання WHO_AM_I і 14 raw bytes, CAPTURE |
| fault on | Діагностика: цільова адреса 0x69 без пристрою, реальний NACK |
| fault off | Повертає 0x68, повторна перевірка та SENSOR_RECOVERED |

Невідомі, не-ASCII та рядки довші за 63 символи відхиляються.
Це протокол рядків, не однолітерні команди. До нього не належать TILT,
скидання alarm або визначення сеансу. B1 викликає baseline після 35 мс стабільного
натискання; утримання не повторює команду.

EVENT містить seq, t у мс, type, mode, severity, ax/ay/az у mg, adc raw і metric.
metric для SHOCK є квадратом зміни вектора в mg²; для LIGHT_CHANGED це ADC delta;
для BODY_MOVED це поріг 20°, не виміряний кут; для SENSOR_ERROR це enum
1=NACK, 2=TIMEOUT, 3=BAD_ID. CAPTURE дає фактичні raw bytes і m°C.
MODE та виміри копіюються до черги в момент події.

Передавання рядків асинхронне через IRQ, буфер RX на 128 байтів.
Черга має 16 записів. Переповнення не мовчазне: QUEUE_OVERFLOW повідомляє
кількість утрачених записів після осушення черги. Номери присвоюються
збереженим записам і збільшуються; після restart починаються заново.
PIR, IMU, ADC та heartbeat опитуються незалежно. NACK не блокує інші канали;
IMU перевіряється кожні 1000 мс, pending orientation скидається під час помилки.
