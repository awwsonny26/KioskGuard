# MPU6050 bring-up

Драйвер перевіряє WHO_AM_I=0x68, виходить зі sleep через PWR_MGMT_1=1,
CONFIG=2, ACCEL_CONFIG=8, GYRO_CONFIG=0, SMPLRT_DIV=4.
З DLPF увімкнено gyro output 1 кГц / (4+1)=200 Гц.
App опитує 50 Гц. DLPF 94 Гц прискорення, затримка близько 3 мс.
Діапазон ±4 g, масштаб 8192 LSB/g: стимул ax=2 g не насичується.
На відміну від порога модуля, KioskGuard перевіряє зміну вектора.

Burst 14 байтів від 0x3B містить accel, temperature, gyro.
Для правил KioskGuard потрібен accel; temperature допомагає перевірити декодування.
Raw big-endian signed int16, mg=raw*1000/8192, m°C=raw*1000/340+36530.
Невдале читання не змінює вихідний sample.

Джерело: RM-MPU-6000A-00 Rev 4.2, §4.2, §4.3, §4.5,
§4.17, §4.18, §4.28, §4.32; PS-MPU-6000A-00 Rev 3.4.
Тайм-аут адаптера обмежено 5 мс на операцію HAL.
HAL приймає адресу, зміщену на один біт, підтверджено локальним HAL_I2C_Mem_Read.
